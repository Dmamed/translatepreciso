# Traductor Preciso

Extensión de navegador (Chrome, Edge, Brave) para traducir con IA textos de filosofía y teología cristiana ortodoxa entre español, inglés, griego y latín. Usa la API de Anthropic.

## Características
- Traducción natural con prioridad en la precisión conceptual
- Español ↔ inglés, y griego/latín → español o inglés
- Terminología cristiana ortodoxa (theosis, Theotokos, pecado ancestral…)
- Reversible: botón "⇄ Revertir" para traducir de vuelta y verificar
- Glosario editable en los ajustes
- Atajo Alt+T

## Instalación
1. Descarga o clona este repositorio.
2. Abre `chrome://extensions` y activa **Modo de desarrollador**.
3. Pulsa **Cargar descomprimida** y elige esta carpeta.
4. En los ajustes, pega tu API key de Anthropic.

## Uso
Selecciona texto, clic derecho → "Traducir con precisión" (automático, → Español o → Inglés), o pulsa Alt+T.

## Privacidad
La API key se guarda solo en el almacenamiento local de tu navegador y el texto seleccionado se envía únicamente a la API de Anthropic. No hay ninguna clave dentro del código.
